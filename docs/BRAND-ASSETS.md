mark, graphite #222623, cream #E8E5DC, and terracotta #BA492F.

The exact user-supplied images were copied without recoloring. The 512px plugin
images in assets/ are part of the portable public ZIP, while the web asset
URLs give reviewers and platform editors a stable place to download artwork.

Directory approval is separate from artwork hosting. Hosting a URL does
not update a publisher's authenticated marketplace listing. OpenAI Platform
requires a verified developer identity for a new upload; a previously created
private ChatGPT Plugin Creator release is also not public-directory approval.

The bundled SVG files and images can be referenced in GitHub documentation.
If your repository settings allow it, the exact social-preview PNG is
assets/github-social-preview-1280x640.png; GitHub may require a separate
authenticated settings upload before using it as the repository preview.
