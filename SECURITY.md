# Security Policy

Please avoid disclosing exploit details, passwords, API keys, or private
repository content in public issues. Use GitHub's **Report a vulnerability**
option in this repository's Security section when private vulnerability
reporting is enabled. If it is unavailable, create a public issue asking
for an out-of-band reporting channel **without including sensitive details**.

Supported server endpoint: https://docsy.remcp.site/mcp
Official project support: https://docsy.remcp.site/support
